# ASHRAM · Mandala Generator

Мини-инструмент: загружаешь фото → собирается мандала (зеркалирование по бренд-правилу) → правишь кроп масштабом и перетаскиванием → накладываешь лого → скачиваешь в трёх форматах.

## Что умеет
- **Форматы:** Пост `1080×1440`, Сторис `1080×1920`, Преза `1920×1080`.
- **Мандала:** фото зеркалится в 4 квадранта (TL оригинал, TR — по горизонтали, BL — по вертикали, BR — по обеим осям).
- **Кроп:** ползунок «Масштаб» + перетаскивание фото мышью — двигаешь тайл, чтобы швы (сходятся по центру) были чистыми, без «грязи».
- **Лого:** вкл/выкл, 5 цветов (жёлтый / белый / коричневый / оранжевый / чёрный), размер (% от ширины кадра), позиция (низ / центр / верх).
- **Экспорт:** PNG текущего формата или все три сразу.

## Запуск локально
Просто открой `index.html` в браузере (двойной клик). Для корректных шрифтов лучше запустить локальный сервер из этой папки:

```bash
npx serve .
# или
python3 -m http.server 8000
```

Затем открой `http://localhost:3000` (serve) или `http://localhost:8000`.

## Деплой на Vercel
Папка — статический сайт, сборка не нужна.

- **Через сайт:** vercel.com → Add New → Project → перетащи папку `mandala-tool` (или подключи гит-репозиторий с ней). Framework preset: **Other**. Deploy.
- **Через CLI:**
  ```bash
  npm i -g vercel
  cd mandala-tool
  vercel
  ```

## Файлы
- `index.html` — всё приложение (разметка + стили + логика в одном файле).
- `fonts/` — фирменные шрифты Ashram (Gaisyr Mono, Monument Grotesk). Это trial-начертания: для внутреннего использования ок, для публичного продакшена нужна лицензия шрифтов.

Лого ASHRAM встроено в `index.html` как SVG и перекрашивается на лету — отдельного файла не требует.
